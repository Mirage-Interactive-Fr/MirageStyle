# MirageStyle for Julia

Mirage Interactive's public Julia formatting rules for Étendue 3D projects.

Projects ship [JuliaFormat.toml](JuliaFormat.toml) at their root. Open the project in VS Code with the official Julia extension and run **Format Document**. The extension loads the configuration automatically.

The rules use JuliaFormatter's Blue style with project-specific options. See the [Julia extension's formatting guide](https://www.julia-vscode.org/docs/stable/userguide/formatter/).
